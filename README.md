# Data Structures and Algorithms in C

A comprehensive collection of Data Structures and Algorithms implemented in the C programming language. This repository is meant for learning, practicing, and revising fundamental DSA concepts through executable C programs.

## Overview

This project includes implementations of several core data structures and algorithms, including:

- Sorting algorithms
- Pointers and dynamic memory allocation
- Linked lists
- Stacks
- Trees
- Graphs

Each folder contains standalone C programs demonstrating a specific concept.
